# Design references

[Home](../README.md)

The Atlas uses an original layout and original diagrams. The following public READMEs informed navigation and presentation. Their prompts, paper summaries, branding and illustrations were not copied. Star counts are a dated popularity snapshot, not a measure of scientific reliability.

| Reference | Stars on 2026-10-02 | Inspected layout | Adopted principle |
|---|---:|---|---|
| [Leey21 / awesome-ai-research-writing](https://github.com/Leey21/awesome-ai-research-writing) | 34,505 | Purpose, opening navigation and two-part contents | State the reader’s task before presenting the collection |
| [sindresorhus / awesome](https://github.com/sindresorhus/awesome) | 513,416 | Centered opening, theme-aware artwork and category navigation | A quiet opening and short, useful navigation |

| [Shubhamsaboo / awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps) | 140,529 | Centered opening, category navigation and starter categories | Browse by the task a reader wants to accomplish |

The first four star counts came from the repositories’ GitHub API records. The fifth came from its GitHub page’s star counter. The inspected portions are layout references; this is not a claim to have read every entry or linked paper in those collections.

Apple’s official guidance on [design principles](https://developer.apple.com/design/human-interface-guidelines/design-principles), [layout](https://developer.apple.com/design/human-interface-guidelines/layout), [typography](https://developer.apple.com/design/human-interface-guidelines/typography) and [color](https://developer.apple.com/design/human-interface-guidelines/color) informed the use of hierarchy, spacing, readable weight, restrained emphasis and appearance-aware contrast. The graphite palette, blue accent and loop illustration are our adaptation to a research index. GitHub controls the page typography and rendering. No Apple artwork, logo or font files are embedded.

The research structure comes from the companion manuscript. Visual references do not determine scientific inclusion or classification. The homepage introduces the argument, the chapter pages follow its subsection order, and the citation index gives a compact route into all referenced works.

External repository licenses remain upstream. Because this repository links to those collections and uses original prose and artwork, it does not redistribute their licensed contents or claim a common license for linked artifacts. A license for the Atlas itself has not yet been selected.
